# Glossary

- **ASR / STT**: automatic speech recognition / speech-to-text. Same thing.
- **Wake word**: a phrase ("hey Rosa") a small always-on model listens for, to start listening properly.
- **Push-to-talk (PTT)**: hold a button while speaking.
- **VAD (voice activity detection)**: a small model that says, for each slice of audio, whether it contains speech.
- **Endpointing / end-of-turn detection**: deciding the speaker has finished. Too eager cuts people off; too patient adds delay.
- **Frame**: a short slice of audio, here 512 samples = 32 ms at 16 kHz.
- **Sample rate**: samples per second. 16 kHz is what speech models expect; mics often record at 48 kHz.
- **Pre-roll**: a little audio kept from just before listening started, so the first word isn't lost.
- **Streaming vs batch**: streaming transcribes while you talk and shows partial text; batch records first, then transcribes.
- **Partial / final**: the live, still-changing transcript vs the finished one.
- **Pseudo-streaming**: re-transcribing the growing recording every so often, for engines that can't stream natively.
- **WER (word error rate)**: (substitutions + deletions + insertions) ÷ words in the correct transcript.
- **Command accuracy**: our stricter score: are all the directions, numbers and units right?
- **Real-time factor (RTF)**: compute time ÷ audio length. Below 1 means faster than real time.
- **Felt delay**: from when you stop speaking to when the final text appears.
- **ONNX / onnxruntime**: a portable model format and the library that runs it on CPU, CUDA or others.
- **MLX**: Apple's machine-learning library for Apple silicon.
- **Metal / CUDA**: the GPU programming layers on Apple and NVIDIA hardware.
- **SSE (Server-Sent Events)**: a simple way for a web server to keep pushing updates to a page.
- **Hotwords / prompt**: domain words given to the STT engine so it prefers them ("centimetres", "Rosa").
